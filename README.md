# 🐧 Linux Learning Journey

### Learning Linux for Cloud Computing & DevOps

A personal learning repository documenting my journey of learning Linux through hands-on practice, command-line exploration, and practical exercises.

---

## 📌 About This Repository

Linux is a fundamental technology behind cloud infrastructure, server administration, networking, and modern DevOps workflows.

This repository serves as my technical learning journal, where I document the concepts I learn, commands I practise, experiments I perform, and problems I solve along the way.

My approach is simple: understand a concept, practise it in a Linux environment, document my findings, and apply that knowledge to real-world scenarios.

The goal is to build a strong foundation in Linux that supports my growth in **Cloud Computing and DevOps Engineering**.

## 🎯 Learning Objectives

- Develop confidence working with the Linux command line.
- Understand Linux fundamentals and system administration.
- Gain practical experience with Linux commands and utilities.
- Develop troubleshooting and problem-solving skills.
- Learn shell scripting and task automation.
- Strengthen networking fundamentals.
- Apply Linux knowledge to cloud infrastructure.
- Build a foundation for learning DevOps tools and workflows.

## 📚 Learning Approach

I follow a hands-on approach to learning Linux:

1. **Learn** — Understand the concept and its purpose.
2. **Practise** — Execute commands and experiment in a Linux environment.
3. **Document** — Record explanations, examples, and observations.
4. **Troubleshoot** — Investigate errors and understand their causes.
5. **Apply** — Connect the knowledge to practical scenarios.

My focus is on understanding how things work rather than simply memorizing commands.
